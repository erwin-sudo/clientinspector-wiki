ClientInspector

ClientInspector is a premium Paper 1.21.4 plugin that gives your staff team complete visibility into every player who joins your server. When a player connects, staff with the appropriate permission receive a rich, interactive notification containing the player's client, version, ping, game mode, health, equipment, effects, flight status, playtime, and much more.

Beyond the join notification, ClientInspector provides 9 powerful subcommands for on-demand player inspection: detailed player lookup, inventory viewing, equipment inspection with enchantments and durability, active potion effects, statistics, and precise location data.

Features

Join Notifications

  • Rich in-game notification sent to all staff on player join
  • Player name is clickable (copies UUID) and hoverable (full tooltip with 45+ fields)
  • Configurable notification sound (customizable name, volume, pitch)
  • 30+ individual display toggles so you see only what matters
  • World blacklist support (suppress notifications in specified worlds)
  • Custom join/quit chat messages for all players

In-Game Data Collected

  • Player identity: name, UUID, display name, list name, OP status, first/last played dates, bed location, last death location, playtime
  • Client: brand (Vanilla, Forge, Fabric, Lunar Client, Badlion, Feather, OptiFine, NeoForge, Geyser, LabyMod, CheatBreaker, etc.), version, protocol number, locale
  • Connection: ping, IP address (with port), world, chunk coordinates
  • Game state: game mode, health, max health, food, saturation, absorption, experience level/total/progress
  • Movement: flying, allow flight, walk speed, fly speed, sneaking, sprinting, swimming, gliding
  • Effects: all active potion effects with amplifier (Roman numerals) and duration
  • Equipment: all 6 armor and item slots with names, amounts, durability, and enchantments
  • Client settings: view distance, chat mode, chat colors, main hand

Plugin Integrations

  • ViaVersion: protocol version and mapped Minecraft version
  • Floodgate/Geyser: Bedrock player detection
  • SuperVanish / PremiumVanish: vanished status
  • EssentialsX: AFK, god mode, mute status, nickname

Commands

  • /ci lookup <player> Full player detail view (50+ fields)
  • /ci invsee <player> Open and edit a player's inventory
  • /ci ecsee <player> Open and edit a player's ender chest
  • /ci equip <player> Equipment with durability and enchantments
  • /ci effects <player> Active potion effects with amplifiers and timers
  • /ci stats <player> Playtime, kills, deaths, K/D, blocks mined, distance walked, jumps, items crafted/enchanted, and more
  • /ci location <player> World, environment, coordinates, yaw/pitch, chunk, biome, light levels, in-game time, weather
  • /ci reload Reload configuration
  • /ci toggle Toggle your own notifications on/off

Discord Webhook

  • Rich embed sent to Discord on player join
  • Configurable embed color, IP visibility toggle
  • Includes player, UUID, version, client, ping, platform, game mode, world, locale, HP, level, OP status, vanish, AFK, god mode, nickname, playtime, effects, flight, equipment

File Logging

  • Append a customizable line to a log file per join
  • 40+ placeholders for any data field
  • Useful for audit trails or external tool integration

  enabled: false
  message: "&8[&a+&8] &7<player_name>"

  enabled: false

webhook:

Installation

  1. Download the ClientInspector jar
  2. Place it in your server's plugins/ folder
  3. Restart your server (or use /reload - though restart is recommended)
  4. Grant permissions to your staff as needed
  5. Optionally configure plugins/ClientInspector/config.yml
  6. Run /ci reload to apply configuration changes

Requirements

  • Paper 1.21.4 (or compatible fork)
  • Java 21+
